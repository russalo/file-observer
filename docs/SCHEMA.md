## safety_flags

- `extraction_permission_bypassed` — owner-locked encrypted PDF: EXTRACT permission not set but metadata extracted anyway (v1.12)
- `has_external_references` — XML contains <!ENTITY with SYSTEM or PUBLIC
- `has_javascript` — PDF contains /JS or /JavaScript markers
- `has_macros` — DOCX contains a vbaProject.bin (requires enable_specialists)
- `has_ole_objects` — RTF contains \objemb or \objlink

## error_codes

- `baseline_decode_failed` — text decoding failed across the full charset cascade
- `json_parse_failed` — JSON parse error during the .json specialist probe
- `mime_type_fallback` — MIME detection fell back to the extension guess (libmagic absent/null)
- `pdf_encryption_unsupported` — AES-encrypted PDF and the cryptography package is absent
- `specialist_probe_failed` — a specialist probe or extraction raised / returned null
- `toml_parse_failed` — TOML parse failed during structural key extraction
- `universal_read_failed` — file open/read failed after stat succeeded (permissions, handle errors)
- `universal_stat_failed` — file stat() failed (deleted mid-scan / permissions / TOCTOU)
- `unsupported_extension` — extension not in the specialist registry and not a recognized common type
- `xml_parse_failed` — XML parse failed during structural key extraction
