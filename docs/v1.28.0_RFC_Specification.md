# v1.28.0 RFC — `--stdout` (manifest to stdout)

**Status: SHIPPED (2026-06-27) — LIVE on PyPI as v1.28.0 (+ the v1.28.1 `[all]`-extra patch). Approved by Russell.** RFC normative language per BCP 14.

| Axis | Current (v1.27.0) | Proposed (v1.28.0) |
|---|---|---|
| SCANNER | 1.27.0 | 1.28.0 |
| LOGIC | 1.14.1 | 1.14.1 (unchanged) |
| SCHEMA | 1.16 | 1.16 (unchanged) |

## 1. Summary

Add a `--stdout` flag: write the manifest to **stdout** (no file, no report), so a
one-shot scan composes in a pipe — `file-observer . --stdout | jq …` — and a container
can emit the manifest cleanly (`docker run … img /data --stdout > manifest.json`).

Today the one-shot scan ALWAYS writes `manifest_v{ver}_{ts}.json` + a markdown report to a
directory (`-o`, default the package's `manifests/`). That's awkward for pipelines and for
a read-only Docker mount.

## 2. Motivation

The prerequisite for the Docker image step (lowering-barriers track) — but a pipeline win on
its own. It aligns FO's one-shot output with its existing stdout surfaces (`--watch` streams
deltas to stdout, `--schema` prints to stdout). Pure output-routing: **what** is emitted is
byte-identical to the file; only **where** it goes changes.

## 3. Design

- `--stdout` (store_true). When set: write `output` (the same `manifest_to_json` /
  `manifest_to_jsonl` string the file would hold) to `sys.stdout` with a trailing newline,
  and **write no file, no markdown report, and no "Manifest written to …" message** (those
  `print()`s go to stdout today and would corrupt the piped manifest). Respects
  `--format json|jsonl`. The stderr progress indicator (`--progress`) is unaffected (already
  stderr-only), so stdout stays clean.
- **Mutually exclusive** with `--output` (pick one destination → exit 2) and `--watch`
  (which already owns stdout with its delta stream → exit 2).

## 4. Observable surface

None — no manifest field/shape/value change. `--stdout` output is byte-identical to the
file the same invocation would write (sans filename/timestamp).

## 5. Version-axis impact

- **SCANNER 1.27.0 → 1.28.0** — a new CLI flag (the v1.9 `--workers` / v1.11 `--watch`
  precedent: a feature with no manifest change).
- **LOGIC 1.14.1 / SCHEMA 1.16 unchanged** — output routing only; the manifest is identical.

## 6. Falsifiable contract

`tests/test_v1_28.py`: `file-observer <dir> --stdout` prints a manifest to stdout whose
`manifest_checksum` equals a programmatic `scan(dir)`; writes NO file (the default
`manifests/` dir gains nothing, the CWD gains nothing); emits no "Manifest written to …" on
stdout; `--format jsonl` yields JSONL on stdout; `--stdout --output X` and `--stdout --watch`
exit 2.

## 7. Review plan

Leg-1 in-house swarm + leg-4 PR bots; falsify-first. No corpus sweep / red-team (manifest
unchanged, no new parser).
